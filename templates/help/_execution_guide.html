Cómo ejecutar y estudiar

  1. Selecciona la operación o el algoritmo e ingresa los datos solicitados.
  2. Usa Ejecutar operación para aplicar o completar la ejecución.
  3. Usa Paso a paso para abrir la traza y navegar con Anterior y Siguiente.
  4. Durante la traza, contrasta el estado visual con el código C y revisa los resultados al finalizar.

Los nombres y datos de entrada cambian según el TAD; la pantalla habilita únicamente los controles que aplican al flujo actual.
