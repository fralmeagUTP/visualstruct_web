Los métodos C siguientes pueden incluir helpers, utilidades sin botón propio y llamadores equivalentes. Un bloque con varias funciones no cambia el nombre de la operación de la aplicación. Las vistas de memoria usan identidades simbólicas; tras free, sus registros históricos no son punteros utilizables.

{% if structure_id == "graph" %}

El C almacena listas enlazadas separadas de vértices y arcos. La aplicación distingue grafos dirigidos y no dirigidos; en estos últimos crea arcos inversos. Los vértices y pesos son enteros int32: un número integral como 2.0 se normaliza; fracciones, no finitos y valores fuera de rango se rechazan. El límite es 200 vértices. Dijkstra rechaza pesos negativos incluso desconectados y usa INT_MAX como infinito. Bellman-Ford distingue un destino inalcanzable de un ciclo negativo alcanzable, que produce error. Prim y Kruskal se ofrecen para grafos no dirigidos y pueden devolver un bosque.

{% endif %} {% if structure_id == "hash_table" %}

Claves y valores son enteros int32. Crear tabla recibe sólo capacidad positiva, como máximo INT_MAX, que permanece fija durante su vida; la carga se calcula como estadística, no configura un rehash. Vaciar conserva los buckets; destruir termina su vida. La aplicación diferencia esas operaciones.

{% endif %} {% if structure_id == "sorting_array" %}

La interfaz admite entre 1 y 80 enteros int32, separados por comas. El catálogo ofrece once algoritmos. Counting y Binsort admiten rango inclusivo máximo−mínimo+1 hasta 1000000; las entradas grandes conservan eventos completos mediante representación dispersa y páginas. Radix separa negativos y no negativos. Las funciones imprimir/copiar/probar del C son utilidades, no algoritmos adicionales del selector.

{% endif %} {% if structure_id == "linked_list" %}

Las posiciones de la API empiezan en 1. Insertar posición coloca el valor antes de esa posición; Insertar elemento permite antes/después según relative. Eliminar posición convierte la posición API a índice interno base 0. Buscar posiciones devuelve posiciones base 1. El alias eliminar_primero retira la primera coincidencia por valor, no la cabeza sin comparar. Los llamadores deben conservar estas conversiones.

{% endif %} {% if structure_id == "sublist" %}

Listar hijos consulta el primer padre coincidente y copia como máximo 1024 hijos en la aplicación; el C respeta la capacidad del destino. El main mostrado es un fragmento para copiar con stdio.h y tad_sublista.h.

{% endif %}

Ejecutar operación crea una llamada; Anterior/Siguiente recorren la misma traza. Cerrar y reactivar Paso a paso no vuelven a ejecutar. Las consultas completadas pueden conservarse en el historial o journal aunque no muten la estructura; los rechazos no agregan llamadas exitosas. Reiniciar borra el estado del módulo.
