Manual de uso de la app

Esta app es un visualizador didactico de estructuras de datos y algoritmos. Combina operaciones reales, interpretacion paso a paso del codigo C y una vista visual para que el usuario comprenda que hace cada metodo, como cambia el estado y por que ocurre ese resultado.

Que es esta app

  • Una herramienta educativa para practicar TAD y algoritmos.
  • Un entorno de simulacion donde el estado visual sigue la logica del metodo ejecutado.
  • Un apoyo para clase, autoestudio, laboratorios y evaluaciones practicas.

Para que sirve

  • Entender estructuras secuenciales, jerarquicas, grafos, hash y ordenamiento.
  • Comparar ejecucion paso a paso vs ejecucion rapida (solo resultado final).
  • Relacionar entradas, salidas, consola C e historial tecnico con el estado visual final.
  • Exportar evidencias visuales en JPG para informes o actividades.

Que se puede hacer

  • Ejecutar operaciones sobre cada estructura (insertar, eliminar, buscar, recorrer, etc.).
  • Simular linea por linea con controles de reproduccion y navegacion por pasos.
  • Ver codigo C, consola C (printf) e historial tecnico cuando el modo tecnico esta activo.
  • Cambiar entre modo visual y modo completo con el switch global.
  • Exportar el estado visual actual con boton Exportar JPG (calidad y escala configurables).

Como funciona (flujo recomendado)

  1. Selecciona un modulo en la barra superior.
  2. Elige estructura, operacion y completa entradas.
  3. Decide el modo de ejecucion:
    • Interpretar codigo paso a paso activado: recorre la traza completa.
    • Interpretar codigo paso a paso desactivado: aplica resultado final.
  4. Pulsa Reproducir o avanza con Siguiente paso.
  5. Valida mensaje funcional, estado visual y (si corresponde) consola/historial.
  6. Si necesitas evidencia, usa Exportar JPG.

Modos didacticos

  • Modo visual (por defecto): reduce carga cognitiva inicial y muestra la parte esencial de interaccion y resultado.
  • Modo completo: muestra codigo C, consola C y detalle tecnico para analisis profundo.

Como leer la salida de la app

  • Estado visual: representa la estructura/algoritmo en el paso actual o final.
  • Mensaje: confirma resultado funcional (exito/error de la operacion).
  • Consola C: muestra salidas printf relevantes de la ruta ejecutada.
  • Historial tecnico: resume operaciones y resultados en secuencia de ejecucion.

Recomendaciones para usuarios nuevos

  • Empieza por Pila o Cola en el modulo secuencial.
  • Activa modo paso a paso para observar cambios de punteros y estados intermedios.
  • Luego practica ABB/AVL para comprender comparaciones y balanceo.
  • En grafos, sigue el flujo: construccion -> recorrido/camino minimo/MST.
  • Usa exportacion JPG para registrar resultados de cada practica.

Accesos rapidos de ayuda

  • Ayuda modulo grafos
  • Ayuda modulo hash
  • Ayuda modulo ordenamiento
