Manual de uso

VisualStruct permite estudiar estructuras de datos y algoritmos mediante una representación visual sincronizada con código C y con el resultado de cada operación.

Flujo de aprendizaje

  1. Elige un módulo y la estructura o algoritmo que quieres estudiar.
  2. Prepara los datos: escribe valores, define la operación o construye el grafo según la pantalla.
  3. Ejecuta para llegar al resultado, o usa el modo Paso a paso para avanzar y retroceder por la traza.
  4. Observa la representación visual, la línea C activa y la salida/resultados de la operación.
  5. Consulta Ayuda para la explicación del TAD y descarga su código C completo cuando quieras revisarlo fuera de la aplicación.

Cómo leer una ejecución

Visualización

Representa el estado actual del TAD o del algoritmo; no es una ilustración independiente del código.

Código C

Resalta la instrucción o método relacionado con el estado que se está explicando.

Resultados

Reúnen mensajes, consola C, historial y la estructura final cuando el módulo los ofrece.

Paso a paso

Permite revisar una traza con Anterior y Siguiente; Ejecutar completa una operación o la traza en curso.

Sobre el código C descargable

La ayuda específica de cada TAD ofrece el archivo fuente principal .c y su encabezado .h. Son fuentes completas del módulo, no fragmentos del panel de ejecución. Lee la nota de dependencias antes de compilarlos; por ejemplo, los recorridos del Grafo usan el TAD Cola.

Accesibilidad y evidencias

El interruptor global permite mostrar más código y detalles técnicos. Cuando el módulo lo habilita, puedes exportar la visualización actual en JPG desde la barra superior.
