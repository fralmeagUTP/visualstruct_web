# Evaluación de usabilidad pedagógica del módulo de ordenamiento

Fecha: 2026-08-23

## Método

Se realizó un recorrido cognitivo reproducible con cinco tareas de comprensión en anchos de escritorio,
tableta y móvil. Las comprobaciones automáticas verifican foco, controles, persistencia y contenido; la
revisión manual se concentra en claridad conceptual y ausencia de información transmitida sólo por color.

| Tarea | Criterio | Resultado |
|---|---|---|
| Preparar un ejemplo con duplicados | Entrada visible y explicación previa | Aprobado |
| Predecir una condición | Resultado oculto, pistas y retroalimentación | Aprobado |
| Relacionar un intercambio con C | Línea, punteros y temporal simultáneos | Aprobado |
| Cambiar a móvil durante un paso | Cursor, estado y narración conservados | Aprobado |
| Comparar dos métodos | Misma entrada; métricas y teoría separadas | Aprobado |

## Hallazgos y correcciones

- Se separó el texto numérico de los símbolos de estado para mantener legibilidad y compatibilidad.
- Se añadieron foco visible, atajos documentados, nombres accesibles y anuncios breves de cambio.
- Se sustituyó el flujo ambiguo de reinicio por acciones separadas para ejecución y datos.
- Se redujo el ejemplo aleatorio recomendado a siete elementos para disminuir carga cognitiva.

## Limitación

Este recorrido no sustituye una evaluación con estudiantes reales. Se recomienda una sesión posterior con
5–8 estudiantes y un docente, midiendo explicación del invariante, predicción y transferencia a código C.
