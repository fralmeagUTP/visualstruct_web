# Tareas

## 1. Diagnóstico y contrato del piloto

- [ ] 1.1 Medir el recorrido actual de Pila en escritorio, tableta y móvil: insertar, ejecutar, reproducir, desapilar y consultar C.
- [x] 1.2 Definir el inventario de información primaria, secundaria y bajo demanda.
- [ ] 1.3 Establecer los límites de alto, ancho, scroll interno, teclado y contraste para el piloto.
- [x] 1.4 Validar el orden pedagógico y la numeración única de las cinco etapas visibles del piloto: Preparar y controlar, Visualizar y ejecutar, Relacionar con código C, Comprender y Reflexionar.

## 2. Diseño del laboratorio de Pila

- [x] 2.1 Crear un área de trabajo principal con estado visual y código C simultáneos, seguida del bloque unificado de preparación y controles.
- [x] 2.2 Mantener visibles la entrada, Ejecutar, Reproducir, Siguiente, estado de simulación y el código activo.
- [x] 2.3 Compactar controles secundarios y navegación extensa en un panel progresivo accesible.
- [x] 2.4 Convertir Predecir, Comprender y Comparar en secciones expandibles sin perder sus identificadores ni su contenido.
- [x] 2.5 Ajustar tipografía, espaciado, jerarquía visual, foco y etiquetas para lectura rápida.
- [x] 2.6 Implementar paneles plegables para Predecir, Comprender y Comparar, cerrados inicialmente y persistentes durante la sesión.

## 3. Adaptación responsive

- [x] 3.1 Implementar la composición de escritorio para 1366×768 y resoluciones mayores.
- [ ] 3.2 Implementar la composición de tableta sin ocultar la operación ni los controles principales.
- [ ] 3.3 Mantener en móvil las pestañas Estado/Código y una zona de control accesible sin superposición.

## 4. Verificación del piloto

- [ ] 4.1 Probar insertar, duplicar, desapilar, preparar, reproducir, pausar y avanzar paso a paso en Pila.
- [ ] 4.2 Confirmar que estado visual y línea C resaltada continúan sincronizados tras el rediseño.
- [ ] 4.3 Ejecutar pruebas de teclado, foco, contraste, navegación interna y reducción de movimiento.
- [ ] 4.4 Ejecutar Playwright con capturas en escritorio, tableta y móvil; validar que la acción principal no requiere scroll de página.
- [ ] 4.5 Presentar el piloto de Pila para aprobación antes de extenderlo a las otras estructuras.
- [ ] 4.6 Verificar que abrir o cerrar paneles no altere la traza, el estado de la pila ni la navegación por teclado.
