# Diseño mínimo sin ampliar arquitectura
Generador local Python estándar recibe perfil/task y produce HTML escapado; navegador lee sólo archivos locales. El HTML muestra objetivo, rol/owner, rutas y siguiente paso como fotografía, sin inventar aprobación ni ejecutar gates/agentes. Estilo en CSS separado para que diseño no cambie semántica de código. Navegación skip-link, foco visible, botón para JSON y layout adaptable; no librerías externas.
Roles reales por el mismo autor: specifications (requisitos/escenarios y aceptación), code (generador y checks aislados), visual (CSS y revisión capturas/teclado/responsive). Documentación local acompaña entregas; QA final distinta del autor. No cinco agentes/perfiles ficticios.
Tareas terminan su ejecución en pending esperando QA, nunca closed por autocertificación. dependencies=[] porque no hay cierres independientes aún; requisitos/artefactos/verificaciones previas se enlazan como base y handoff explícito después de verify, conservando snapshots. No se afirma cierre de dependencia pendiente ni demostración de gates de dependencia entre tareas cerradas. Un solo active y escritura secuencial. Cierre de cada tarea necesitará QA real sobre hashes finales.
Pruebas específicas de ejemplo, no repetir suites del núcleo cerrado. Playwright Chromium ya instalado; file://, headless y peticiones externas abortadas. Comprobación visual local no valida UI de aplicación ni conformidad WCAG completa. LOW.
