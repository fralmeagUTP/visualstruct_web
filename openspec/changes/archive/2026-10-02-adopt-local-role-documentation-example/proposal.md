# Adoptar roles restantes en ejemplo local documental
## Why
El núcleo y el piloto documental están cerrados y aceptados; falta ejecución real pertinente de specifications, code y visual. Un ejemplo HTML local permite probar esos roles sin alterar el producto ni repetir el núcleo.
## What Changes
Crear requisitos/escenarios, generador estándar Python y ejemplo HTML de una tarea persistida, estilo accesible/responsive y manual. Un autor cambia de rol explícitamente y transfiere escritura secuencial; QA será la tarea independiente existente.
## Impact
Sólo esta carpeta del change y su binding de continuidad. Sin app/tests app/auditoría/preview, red/API/agentes, motor autónomo o despliegue. Cambio abierto hasta QA.
