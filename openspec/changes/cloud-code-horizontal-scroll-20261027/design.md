# Diseño
Contrato compartido en ClassroomView: marcar únicamente contenido C (no consola), white-space pre, overflow-wrap normal y líneas de ancho intrínseco dentro de contenedores min-width 0 / max-width 100%. Barras locales de tamaño visible; sin scrollIntoView horizontal ni cambios a fuentes. Conservar el mismo nodo al ampliar y restaurar su posición al cerrar.
