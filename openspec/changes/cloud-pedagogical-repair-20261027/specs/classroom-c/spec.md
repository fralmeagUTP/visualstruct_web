## ADDED Requirements
### Requirement: Código C reproducible en clase
Las descargas C/H y programas main ofrecidos como reproducibles DEBEN corresponder a la implementación enseñada y ejecutarse con las dependencias documentadas.
#### Scenario: Descarga y compilación
- **GIVEN** una estructura y un historial válido
- **WHEN** se descargan las fuentes y se compila el programa con C17
- **THEN** el resultado observable coincide con las operaciones reales y la propiedad reservada se libera al finalizar.
#### Scenario: Memoria pedagógica
- **GIVEN** una instrucción de reserva, enlace o liberación
- **WHEN** se avanza o retrocede
- **THEN** la visualización representa su efecto causal y distingue identidades simbólicas de direcciones reales.
