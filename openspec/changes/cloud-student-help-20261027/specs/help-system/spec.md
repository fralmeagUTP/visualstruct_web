## MODIFIED Requirements
### Requirement: Manual y ayudas progresivas
La ayuda DEBE explicar controles reales, resultados y límites actuales con lenguaje para estudiantes y acceso a referencia C completa.
#### Scenario: Primera práctica
- GIVEN una sesión nueva
- WHEN el estudiante abre Manual
- THEN puede seguir un ejemplo de cinco minutos, entender pila y comparar normal/pasos sin confundir navegación con nuevas operaciones.
#### Scenario: Entrada múltiple
- GIVEN una de las ocho estructuras compatibles
- WHEN consulta Agregar varios
- THEN conoce formato, máximo 50, duplicados, avance manual entre valores y conservación de operaciones aceptadas al detener.
#### Scenario: Referencia vigente
- GIVEN una ayuda de cualquiera de las cinco familias
- WHEN consulta ejecución, código o errores
- THEN encuentra enlaces válidos, contratos vigentes y detalle avanzado desplegable sin bitácoras internas.
