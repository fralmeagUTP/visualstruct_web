# Ayuda para estudiantes
La guía mezcla contratos superados y bitácoras técnicas con instrucciones de uso. Se sustituye por una ruta breve de inicio, referencia progresiva y soluciones prácticas, preservando la fotografía anterior como evidencia. Incluye vista de clase y entrada múltiple autorizadas. Sólo plantillas help y documentación; no altera ejecución, fuentes C, backend ni controles.
