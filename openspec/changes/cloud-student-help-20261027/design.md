## Revisión de legibilidad tras fallo real (13:05UTC)
La primera revisión no había inspeccionado el contenido real de summaries jerárquicos: PASS HTTP y enlaces no demostraba comprensión. Se añade plantilla de contenido editorial _student_start exclusiva de ayuda, sin alterar los198Python ni metadata usada por Comprender. Cada TAD: introducción25–31palabras, ejemplo3–5valores y expectativa, tres observaciones concretas, acceso inmediato a práctica. _technical_notes conserva frases esenciales anteriores en listas por operación/tema. No se limita a ocultar el mismo muro; se separan Buscar/Mínimo/Altura/Limpiar/Eliminar/Contar/Validar/etc. Fichas sorting se abren de una en una, con propiedades en viñetas y símbolos de complejidad definidos. Glosarios/funciones auxiliares distinguidos. Lectura humana sigue obligatoria: umbrales p/li/dd80visibles/100avanzados no garantizan comprensión; se mide también acumulación por sección.
